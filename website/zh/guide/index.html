使用指南

安装 第一次播放 常用操作 视频来源 问题排查

IMMIVIO / 开始使用

从这里开始。

选好安装包，打开自己的视频，再把画面调整到舒服的位置。

本页说明 v0.9.5 的功能。对应 APK 会在构建校验完成后附加到发布页；较早安装包以自身发布说明为准。

01 / 安装到头显

  1. 在 下载页选择 Quest、PICO 或实验性 OpenXR 包。
  2. 开启头显的开发者模式，通过 USB 连接电脑并允许调试。
  3. 用你常用的侧载工具安装下载的 APK。下载文件应以 .apk 结尾，源码压缩包不能直接安装。
  4. 从设备的侧载应用列表启动 Immivio。
更新安装需要匹配的应用 ID 和签名。来自其他发布者或部分 CI 的包可能无法覆盖已有安装；请先查看发布说明，保留原应用和数据。

web 版本在“设置 → 关于”提供“检查更新”，默认 appstore 版本不显示此按钮。web 版本仅在您点击后连接 GitHub；播放器只打开发布页面，不会自动下载 APK。

02 / 播放第一个视频

  1. 从资料库打开本地文件，按需允许访问所选文件或目录。v0.9.5 也支持从 Android 文件管理器打开或分享符合条件的视频，访问权限由来源应用提供。
  2. 选择片源对应的投影和立体布局，再检查左右眼顺序。
  3. 播放控件的小按钮可调整字幕、速度、颜色和瞳距；长按 Home 居中，音量跟随头显系统设置。
内容 起步设置
普通视频 平面 + 单目
左右／上下立体视频 按片源选择 SBS／TB；投影另行设置
VR180 鱼眼 SBS 鱼眼 + SBS；视场角按片源设置
360° 等距柱状视频 360° + 与片源匹配的单目／立体布局

这些是起步设置，并非自动识别保证。文件名、编码元数据和实际内容不一致时，需要手动调整。

03 / 常用操作

打开播放控件 左手 Menu 键，或用扳机点按画面。v0.9.5 的左手手掌菜单手势固定可用，捏合可另选左手、右手或双手。
选择与调整 手柄射线 + 扳机，抬起时确认下拉选项；滑块可按住拖动。摇杆用于滚动，不会替你选择选项。
移动界面 按住抓握键拖动画面或资料库窗口；支持的位置可用同手摇杆调距离。
滚动 打开列表或设置时使用摇杆。列表优先于播放快捷操作。
躺卧观看 设置 → 常规 → 躺卧模式；跟随另行控制。
返回资料库 选择“关闭视频”，回到先前浏览的位置。

字幕、校时与队列

从字幕面板选择文字轨道，或手动加载 SRT、ASS、SSA、VTT。同步弹窗可分别提前／延后字幕和音频最多 10 秒。播放队列支持顺序或随机，最后一项结束后返回资料库。

v0.9.5 可打开“双语字幕”，用“主字幕／第二字幕”切换选轨目标。主字幕在上，第二字幕在下，二者共用同一字幕延迟。主字幕关闭时两者隐藏，但保留第二轨选择；把主字幕切到第二字幕使用的同一轨道时，第二字幕会关闭。位图字幕不在支持范围。

外挂文字字幕支持自动检测编码，手动编码选择在重新打开视频后生效。“字幕放在画面下方”仅用于平面视频，包括 SBS／TB 和旋转、躺卧放置；沉浸式模式继续使用画面内的投影字幕。布局与第二轨按视频记忆，并受历史和逐文件记忆开关控制。

文字字幕有五种配色。播放音量跟随头显系统音量；应用的关闭与重开使用头显系统控制。

点击滑块旁的重置图标，只恢复这一项的默认值。调色保留原色、暖色、冷色和自定义；“重置本页”只恢复当前弹窗的三个参数，“重置自定义”恢复全部自定义参数。字幕、校时、双眼校正滑块也可分别重置，关闭的效果保持关闭。旧日光设置会恢复为原色，并保留已记住的自定义参数。

媒体库、银幕与v0.9.5 功能

在 PICO 上，可通过「资源库 → 未知来源 → Immivio」进入侧载的 VR 播放器。

点击视频工具栏的文件夹图标，可在播放时浏览选片。支持紧凑／完整媒体库与列表／图标切换。在通用设置中开启目录位置记忆；关闭播放历史后，新位置只保留在本次运行中。

点击锁图标可将控制栏固定在空间中，在显示设置中调整底板透明度。银幕布局提供电视与巨幕预设、距离、大小、曲率、视线高度和临时定位网格。开启“固定观看默认值”后，临时调整不会覆盖默认布局；“保存为默认”可主动更新它。

STRM 文件填写一个可访问的媒体地址，可从本地或 SMB 浏览打开。通过系统文件选择器打开时，请填写完整地址；SMB 目标需先添加匹配的连接。加载时显示阶段与等待时间，可测量时显示视频读取速度；播放失败后可查看原因并返回媒体库。

v0.9.5 平面视频支持 0.1–50 米距离和 5%–3000% 大小；固定预设与原有记忆仍保留。资料库窗口可用抓握键与同手摇杆调距离，曲面菜单半径随观看距离调整。显示设置只列出设备支持的刷新率，默认优先 72 Hz。

04 / 连接视频资料库

资料库支持本地文件、SMB、DLNA、Plex、Emby、Jellyfin、XBVR 等支持的媒体服务器。从“网络媒体”添加来源，SMB、DLNA 与各媒体服务器并列显示，再填写该来源要求的地址与授权信息。网络目录、收藏、外挂字幕和文件管理能力会因来源而异。

文件列表仅显示视频与文件夹，本地、SMB 和 DLNA 来源统一按视频浏览。MV-HEVC 双视图视频播放尚未验证。

Immivio 播放已有立体内容，不把 2D 生成为 3D。

v0.9.5 可在 Emby／Jellyfin 详情页选择直接播放版本，各版本保留本机的续播、模式和轨道偏好。其他客户端观看非默认版本后的进度不一定会被这里采用，默认入口也可能使用较旧的群组进度。播放历史关闭时，不再发送新的服务器播放回报。

05 / 遇到问题时

画面分裂、变形或立体反转

检查平面／180°／鱼眼／360° 投影，检查单目／SBS／TB 布局；必要时交换左右眼。软件双眼校准不改变头显镜片或硬件瞳距。

播放不流畅

尝试更低码率的内容，再核对设备、编码与构建能力。8K 文件在虚拟机中可解码，不代表头显达到特定帧率。

字幕没出现

检查字幕轨道是否关闭，外挂文件是否仍可访问。请使用 SRT、ASS、SSA、VTT 文本字幕；当前不提供位图字幕轨道。
