使用指南

Immivio 快速上手

安装应用、播放第一个 3D 视频、连接你的片库。本指南适用于 0.9.7 版本。

01安装到头显

  1. 在下载区获取与头显对应的 APK：Meta Quest、PICO，或实验性的 OpenXR 版本。
  2. 在头显上开启开发者模式，用 USB 连接电脑并允许调试。
  3. 使用任意侧载工具安装 APK。安装包以 .apk 结尾；源代码压缩包仅供开发者使用。
  4. 在头显应用库的未知来源中打开 Immivio。PICO：资源库 → 未知来源 → Immivio。
关于更新。只有应用 ID 和签名密钥都一致时，新 APK 才能覆盖安装。从 0.9.4 起，应用 ID 为 com.northboundwisdom.immivio，与旧版 Thru3D 播放器并存安装，旧数据不会自动迁移。

商店版与官网版

商店版不提供检查更新。官网版在设置 → 关于 → 检查更新中提供手动检查：只有你点击时才会连接 GitHub，并在浏览器中打开发布页面。Immivio 不会自行下载或安装 APK。

02播放第一个视频

  1. 打开本地文件或网络媒体，只授权你想使用的文件夹或服务器。
  2. 选择一个视频。
  3. 确认自动识别的立体格式，并按片源调整投影方式：

播放器会结合文件名、容器标记和画面内容识别左右／上下立体视频。黑画面会稍后重试，判断不明确时保留当前模式。已保存的手动选择优先；如需重新识别，在视频模式 → 自动识别中触发。画面匹配判断立体排列，VR 投影和镜头角度仍沿用文件标记或你的设置。

片源 投影方式 立体格式
普通 2D 视频 平面 单眼
左右 3D 平面 左右（全宽或半宽）
上下 3D 平面 上下（全高或半高）
VR180 180° 与片源一致：单眼、左右或上下
VR180 鱼眼 鱼眼 左右
360° 等距柱状 360° 与片源一致：单眼、左右或上下
以上只是起点。文件名、元数据和实际画面不一致时，以画面为准：先检查投影方式，再检查立体格式，最后尝试交换左右眼。

03基本操作

操作 方法
显示或隐藏控制栏 按左手柄菜单键，或用扳机点击画面。左手掌心手势也可以。
选择 用手柄射线指向目标并按扳机。也支持手势指向和捏合。
调节滑块 按住扳机拖动。滑块旁的重置图标只恢复这一项。
移动画面或窗口 按住握持键。支持时可用同一只手的摇杆调整距离。
滚动列表 列表打开时使用摇杆。列表优先于播放快捷操作。
快进快退 拖动进度条；没有打开列表或滑块时，也可左右推摇杆。
调整沉浸式画面 左手握持 + 摇杆移动画面；右手握持 + 摇杆缩放或调整水平双眼对齐。
重新居中 长按头显的 Home 键。
音量 使用头显系统音量控制。
返回片库 选择关闭视频，回到之前浏览的位置。
捏合手 设置 → 通用 → 捏合／菜单手：左手、右手或双手。

04连接你的片库

本地文件

浏览头显中的视频，以及系统已挂载的 U 盘。Immivio 也可以打开从 Android“打开方式”或“分享”菜单发来的视频，以及指向视频地址的 STRM 文件。

网络媒体

选择网络媒体 → 添加来源，再选择 SMB、DLNA、Emby、Jellyfin、Plex、Stash 或 XBVR，填写地址和所需的登录信息。浏览、收藏、外挂字幕和文件操作是否可用，取决于来源和账号权限。

  • 文件列表只显示视频和文件夹，可切换列表／图标视图。播放时，“浏览”会打开控制栏上方的紧凑换片窗口；关闭视频后返回完整媒体库和设置。
  • Immivio 可以记住每个文件夹的浏览位置；关闭播放记录后，新位置只在本次使用中保留。
  • Emby 和 Jellyfin 可选择能直接播放的影片版本，每个版本分别记住进度和设置。
  • 开启播放记录时，播放进度会同步到 Emby 和 Jellyfin 服务器；关闭后不再发送新的记录。

05画面与舒适度

  • 平面画面距离可调 0.1–50 米、大小 5–3000%，弯曲程度可调，并有电视和影院预设；临时网格可辅助摆放。
  • 开启固定观看默认值后，临时调整不会覆盖你的默认布局；保存为默认则会主动替换。
  • 设置 → 显示 → 窗口高度可上下移动菜单，窗口默认下移 12 厘米。
  • 躺着看请开启设置 → 显示 → 躺姿模式；画面跟随是单独的设置。
  • 控制栏底板透明度可在设置 → 外观中调整。
  • 显示设置只列出头显支持的刷新率，并优先使用 72 Hz。

06字幕与播放

  • 选择内嵌文字字幕，或加载 SRT、ASS、SSA、VTT 文件。文字编码会自动识别；手动指定的编码在重新打开视频时生效。
  • 开启双语字幕，在主字幕和副字幕之间切换来分别选择两条字幕。主字幕显示在上方，两者共用一个延迟。
  • 字幕有五种配色。平面视频可把字幕放在画面下方，布局按视频记住。
  • 同步小窗可分别调整音频和字幕时间，各自最多 10 秒。
  • 调色提供原始、暖色、冷色和自定义；“重置本页”恢复当前小窗，“重置自定义”恢复全部自定义参数。
  • 播放队列支持顺序或随机播放，最后一个视频结束后回到片库。
  • 不支持图形字幕。

07常见问题

3D 画面分开、重影或变形

先检查投影方式（平面、180°、鱼眼或 360°），再检查立体格式（单眼、左右或上下），必要时交换左右眼。软件中的双眼对齐不会改变头显镜片或物理瞳距。

播放卡顿

试试同一影片的较低码率版本，并确认头显解码器支持该编码。实际表现取决于编码、码率、分辨率和硬件。

字幕不显示

确认已选择字幕轨道，且外挂字幕文件仍可访问。请使用 SRT、ASS、SSA 或 VTT 文字字幕。

U 盘没有出现

Immivio 使用系统已挂载的存储卷。请检查存储权限和挂载状态，然后重新连接。部分 PICO 系统路径可能仍无法访问。

反馈问题

请在 GitHub Issues 中提交，写明头显型号、Immivio 版本、视频格式和复现步骤。可以在应用中保存本地问题记录，自行决定是否附上。只分享你有权分发的示例，切勿公开密码或私人影片。
