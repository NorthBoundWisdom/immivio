使用指南

安装 第一次播放 常用操作 媒体来源与照片 问题排查

IMMIVIO / 开始使用

从这里开始。

选好安装包，打开自己的视频，再把画面调整到舒服的位置。

01 / 安装到头显

  1. 在 下载页选择 Quest、PICO 或实验性 OpenXR 包。
  2. 开启头显的开发者模式，通过 USB 连接电脑并允许调试。
  3. 用你常用的侧载工具安装下载的 APK。下载文件应以 .apk 结尾，源码压缩包不能直接安装。
  4. 从设备的侧载应用列表启动 Immivio。
更新安装需要匹配的应用 ID 和签名。来自其他发布者或部分 CI 的包可能无法覆盖已有安装；请先查看发布说明，保留原应用和数据。

02 / 播放第一个视频

  1. 从资料库打开本地文件，按需允许访问所选文件或目录。
  2. 选择片源对应的投影和立体布局，再检查左右眼顺序。
  3. 播放控件的小按钮可调整字幕、速度、颜色和瞳距；长按 Home 居中，音量跟随头显系统设置。
内容 起步设置
普通视频 平面 + 单目
左右／上下立体视频 按片源选择 SBS／TB；投影另行设置
VR180 鱼眼 SBS 鱼眼 + SBS；视场角按片源设置
360° 等距柱状视频 360° + 与片源匹配的单目／立体布局

这些是起步设置，并非自动识别保证。文件名、编码元数据和实际内容不一致时，需要手动调整。

03 / 常用操作

打开播放控件 左手 Menu 键，或用扳机点按画面。
选择与调整 手柄射线 + 扳机；滑块可按住拖动。
移动界面 按住抓握键拖动画面或资料库窗口；支持的位置可用同手摇杆调距离。
滚动 打开列表或设置时使用摇杆。列表优先于播放快捷操作。
躺卧观看 设置 → 常规 → 躺卧模式；跟随另行控制。
返回资料库 选择“关闭视频”，回到先前浏览的位置。

字幕、校时与队列

在字幕按钮中选择轨道，或手动加载 SRT、ASS、SSA、VTT。同步弹窗可分别提前／延后字幕和音频最多 10 秒。当前视频播完后自动播放队列中的下一项，最后一项播完后返回文件页面。播放队列可保存顺序，也可按需开启随机播放。

当前开发版可按视频保存明确选择的字幕和音轨，文字字幕有五种配色；播放音量直接跟随头显系统音量。是否包含这些功能，请查看你的 APK 发布说明。

点击滑块旁的重置图标，只恢复这一项的默认值。调色保留原色、暖色、冷色和自定义；“重置本页”只恢复当前弹窗的三个参数，“重置自定义”恢复全部自定义参数。字幕、校时、双眼校正和照片滑块也可分别重置，关闭的效果保持关闭。旧日光设置会恢复为原色，并保留已记住的自定义参数。

04 / 连接资料库，浏览照片

资料库支持本地文件、SMB、WebDAV、DLNA 和支持的媒体服务器。先添加来源，再填写该来源要求的地址与授权信息。网络目录、收藏、外挂字幕和文件管理能力会因来源而异。

照片支持单图、侧边预览、照片墙和记忆碎片。当前开发版的照片墙可以选择 1～3 行。支持范围内的 HEIC／HEIF 空间照片可保留双眼视图； MV-HEVC 双视图视频播放尚未验证。

Immivio 播放已有立体内容，不把 2D 生成为 3D；照片解码能力取决于 Android 设备与片源。

05 / 遇到问题时

画面分裂、变形或立体反转

检查平面／180°／鱼眼／360° 投影，检查单目／SBS／TB 布局；必要时交换左右眼。软件双眼校准不改变头显镜片或硬件瞳距。

播放不流畅

尝试更低码率的内容，再核对设备、编码与构建能力。8K 文件在虚拟机中可解码，不代表头显达到特定帧率。

字幕没出现

检查字幕轨道是否关闭，外挂文件是否仍可访问。请使用 SRT、ASS、SSA、VTT 文本字幕；当前不提供位图字幕轨道。

报告问题

在 Issues 中提供设备型号、构建版本、格式和复现步骤。仅上传有权分发的样片，不公开账号凭据。
