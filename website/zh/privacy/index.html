隐私政策

我们不收集用户数据。

生效及更新日期：2026 年 11 月 5 日

维护者不采集用户数据。播放所需信息在本机处理，或发送至您主动选择的服务。没有开发者行为分析，也不会自动上传诊断报告。

1. 适用范围与维护者

本政策适用于由 NorthBoundWisdom 独立维护的 Immivio 官方应用与官网。“我们”指项目维护者，不包括操作系统、头显平台、网站托管方，或您自行选择的媒体服务提供方。

2. 我们不收集用户数据

我们不通过应用或官网收集您的个人数据。我们不运营用户数据采集后台，不要求注册 Immivio 账号，不植入广告或行为分析 SDK，不出售用户数据，也不建立广告画像。

Immivio 不会向维护者自动上传您的媒体内容、账号凭据、播放历史、设备标识、交互或追踪输入、诊断报告。

3. 仅在本机处理的信息

为实现您使用的功能，应用会在本机处理以下信息：

  • 您选择的视频、字幕与关联音轨，以及目录列表和您主动执行的文件操作。
  • 偏好设置、播放进度、历史记录、书签、来源连接、账号凭据或授权令牌，以及缩略图缓存。
  • 用于本地 XR 交互的头部、控制器与手部输入，以及排查故障所需的本地诊断信息。

这些本地操作不等于维护者采集数据。系统权限仅用于对应的设备功能；您可以在系统设置中撤销权限，相关功能可能因此不可用。

4. 您主动使用的联网功能

联网功能会与完成您请求所需的来源或服务通信。对应服务可能接收您的 IP 地址、验证信息与请求内容。这与 Immivio 维护者收集数据是两回事。

  • 媒体来源：SMB、DLNA 和您配置的媒体服务器会接收设备发现、账号验证、目录浏览、封面或字幕读取、媒体播放等请求。Plex 授权会与 Plex 通信。
  • 服务器播放记录：启用播放历史时，受支持的 Emby／Jellyfin 连接可向您选择的服务器发送播放开始、进度和停止信息。关闭历史记录可停止新的播放回报；已经发出的请求无法撤回。
  • 更新与外部页面：在 web 版本中，您主动检查更新时，应用会访问 GitHub，并在请求的 User-Agent 中携带应用版本。打开发行页面或下载安装包会使用 GitHub 或系统浏览器。应用启动时不会自动检查更新。

请使用您信任的来源，并了解其隐私政策。删除连接或清除本机应用数据，不会删除媒体服务器、Plex、GitHub 或头显平台已经保存的记录。

5. 官网托管与浏览器存储

官网没有广告、访问分析、追踪像素，也不会通过本站代码设置追踪 Cookie。深浅主题选择仅保存在浏览器的本地存储 immivio-theme 中，本站代码不会传输这个值。

官网由 GitHub Pages 托管。GitHub 官方说明会为安全目的记录访问者 IP 地址。托管与下载请求适用 GitHub 自身的处理规则，因此本政策不会承诺托管方也完全不处理任何数据。详情请参阅 GitHub Pages 数据处理说明及 GitHub 隐私声明。

6. 您的控制与自愿反馈

您可以在应用中管理播放历史和缓存、移除已保存的连接、撤销系统权限，也可以通过设备设置清除应用数据或卸载应用。操作系统备份和第三方账号记录由相应平台管理。

诊断日志保存在本机，除非您主动导出或分享。导出日志只会在设备上保存文件，不会自动发送给我们。

如果您自愿通过 GitHub Issues 提交问题、评论或诊断附件，维护者可阅读您提交的内容，GitHub 会依其政策处理。这是您主动发起的沟通，不是后台采集。公开问题中的内容可被他人看到，请勿提交密码、令牌、私人媒体或其他敏感信息；您在 GitHub 提交的内容可通过 GitHub 提供的功能管理。

7. 政策变更与联系

政策调整将在本页公布并更新日期。数据处理方式发生实质变化时，应在变化生效前说明；仅修改本页不会自动授权新的数据收集。

如有隐私问题，请通过项目问题反馈入口联系维护者，先提供不含敏感信息的说明，不要在公开问题中填写私人信息。本政策对包括未成年用户在内的所有用户采用相同的不收集原则，我们不要求提供年龄信息。
