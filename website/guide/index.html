IMMIVIO / GETTING STARTED

Start with your own media.

Choose an APK, open a video, and put the picture where you want it.

01 / Install on your headset

  1. Choose Quest, PICO or experimental OpenXR on the download page.
  2. Enable developer mode, connect your headset by USB, and approve debugging.
  3. Install the downloaded APK with your preferred sideloading tool. The file should end in .apk; source archives are for developers.
  4. Launch Immivio from the headset’s sideloaded-app library.
An update needs a matching application ID and signing key. Packages from other distributors or some CI builds may not update an existing installation. Check the release notes and keep your current app and data until you have confirmed compatibility.

02 / Play your first video

  1. Open a local file in the library and grant access to the file or folder you want to use.
  2. Match the projection and stereo layout to your source, then check eye order.
  3. Use the compact playback buttons for subtitles, speed, color and stereo alignment. Long-press Home to recenter; use the headset’s system volume controls.
Media Start with
Ordinary video Flat + mono
Side-by-side / top-bottom stereo SBS / TB to match the source; choose projection separately
VR180 SBS fisheye Fisheye + SBS; match field of view to the source
360° equirectangular video 360° + the source’s mono/stereo layout

These are starting points, not a guarantee of automatic detection. Adjust manually when names, metadata and actual content disagree.

03 / Everyday controls

Show playback controls Left Menu button, or tap the picture with the trigger.
Select and adjust Point a controller ray and press the trigger. Hold and drag sliders.
Move the interface Hold grip to move a picture or library window. Use the same hand’s thumbstick for distance where supported.
Scroll Use a thumbstick in an open list or settings view. Lists take priority over playback shortcuts.
Watch reclined Settings → General → Reclining mode. Follow is controlled separately.
Return to the library Choose Close video to return to the previous browsing location.

Subtitles, timing and queues

Select a subtitle track or load SRT, ASS, SSA or VTT from the subtitle controls. The synchronization popup adjusts audio and subtitle timing independently by up to ten seconds. Playback automatically advances to the next queued video and returns to the file browser after the last one. Save a queue and optionally enable shuffle.

The current development build remembers explicit audio/subtitle choices per video and offers five text-caption palettes. Playback volume follows the headset’s system volume. Check your APK’s release notes for availability.

Use the reset icon beside a slider to restore just that value. Grading offers Original, Warm, Cool and Custom; Reset page restores only the three fields in the current popup, while Reset custom restores the entire custom look. Subtitle, timing, eye-alignment and photo sliders reset independently. Resets leave disabled effects off. Older Daylight settings use Original and retain remembered custom values.

04 / Connect a library. Explore photos.

Use local files, SMB, WebDAV, DLNA or supported media servers. Add a source, then supply its address and required authorization. Browsing, favorites, sidecar subtitles and file management depend on the source.

Photos can be viewed individually, with side previews, on a photo wall or as memory fragments. The development build supports 1–3 wall rows. Supported HEIC/HEIF spatial photos retain their stereo views. MV-HEVC dual-view video playback has not been validated.

Immivio displays existing stereo content and does not generate 3D from 2D. Photo decoding depends on the Android device and source format.

05 / When something needs attention

Split, distorted or inverted stereo

Check Flat/180°/Fisheye/360° projection, then mono/SBS/TB layout. Swap eyes if necessary. Software eye alignment does not change headset lenses or physical IPD.

Slow playback

Try lower-bitrate media and check the device, codec and build capabilities. Decoding an 8K file in an emulator does not establish a headset frame-rate target.

Missing subtitles

Check that a track is selected and any external file is still accessible. Use SRT, ASS, SSA or VTT text subtitles; bitmap subtitle tracks are not offered.

Report an issue

Include your headset, build version, media format and reproduction steps in Issues. Share samples only when you have distribution permission, and keep credentials private.
