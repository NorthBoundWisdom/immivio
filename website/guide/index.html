User guide

Getting started with Immivio

Install the app, play your first 3D video and set up your library. This guide covers version 0.9.9.

On this page

01Install on your headset

  1. Download the APK for your headset from the download section: Meta Quest, PICO, or the experimental OpenXR build.
  2. Turn on developer mode on the headset, connect it to your computer over USB and allow debugging.
  3. Install the APK with any sideloading tool. The file ends in .apk; source archives are for developers.
  4. Open Immivio from the unknown-source apps in your headset library. On PICO: Library → Unknown sources → Immivio.
Updating. A new APK installs over your current app only when the application ID and signing key match. Since 0.9.4 the ID is com.northboundwisdom.immivio, which installs alongside the older Thru3D player without migrating its data.

Store and website builds

Store builds have no update check. Website builds add Settings → About → Check for updates, which contacts GitHub only when you select it and then opens the release page in the browser. Immivio never downloads or installs an APK by itself.

02Play your first video

  1. Open Local files or Network media and grant access only to the folders or servers you want to use.
  2. Choose a video.
  3. Check the detected stereo layout, then choose the projection to match the file:

Immivio recognizes side-by-side and top-bottom video from filenames, container tags and matching eye images. It retries after black opening frames and keeps the current mode when uncertain. Saved manual choices take priority; use Video mode → Auto detect to recheck a saved format. Image matching identifies stereo packing; VR projection and lens angle follow file markers or your settings.

Your file Projection Stereo layout
Ordinary 2D video Flat Mono
3D side-by-side Flat SBS (full or half width)
3D top-bottom Flat TB (full or half height)
VR180 180° As the source: mono, SBS or TB
VR180 fisheye Fisheye SBS
360° equirectangular 360° As the source: mono, SBS or TB
These are starting points. When the file name, metadata and the picture disagree, trust the picture: check the projection first, then the stereo layout, then swap eyes.

03Everyday controls

Volume Use the headset's system volume controls.
Back to the library Choose Close video to return to where you were browsing.
Pinch hand Settings → General → Pinch/menu hand: Left, Right or Both.

04Connect your library

Local files

Browse videos on the headset and on USB drives mounted by the system. Immivio also opens videos sent from Android's Open or Share menu, and STRM files that point to a video address.

Network media

Choose Network media → Add source and pick SMB, DLNA, Emby, Jellyfin, Plex, Stash or XBVR, then enter the address and sign-in the source needs. Browsing, favorites, sidecar subtitles and file operations depend on the source and your account permissions.

  • File lists show only videos and folders, with list and icon views. During playback, Browse opens a compact video switcher above the controls. Close the video to return to the full library and Settings.
  • Immivio can remember each folder's position. With playback history turned off, new positions last only for the current session.
  • For Emby and Jellyfin, choose a directly playable version of a film; each version keeps its own progress and settings.
  • With playback history on, Emby and Jellyfin receive your playback progress. Turn history off to stop new reports.

05Screen and comfort

  • Flat screens range from 0.1–50 m away and 5–3000% in size, with adjustable curvature and TV or cinema presets. A temporary grid helps with positioning.
  • Fix viewing defaults keeps temporary changes from replacing your preferred layout; Save as default replaces it on purpose.
  • Settings → Display → Window height moves menus up or down. Windows sit 12 cm lower by default.
  • Settings → Display → Reclining mode is for watching lying back. Follow is a separate setting.
  • Under Settings → Appearance, choose a background, adjust its direction and brightness, or set the control bar's opacity. New installations start with Starry night; saved background choices are preserved. Sunset and Beach use photographic panoramas.
  • Display settings list only the refresh rates your headset offers, and prefer 72 Hz.

06Subtitles and playback

  • Choose a text track or load an SRT, ASS, SSA or VTT file. Encodings are detected automatically; a manual choice applies when you reopen the video.
  • Turn on Dual subtitles and switch between the Primary and Secondary targets to choose two tracks. Primary appears above secondary, and both share one delay.
  • Captions come in five color palettes. For flat video, you can place them below the screen; the layout is remembered per video.
  • The sync popup adjusts audio and subtitle timing separately, by up to ten seconds each.
  • Color grading offers Original, Warm, Cool and Custom. Reset page restores the current popup; Reset custom restores the whole custom look.
  • Queues play in sequence or shuffled, and return to the library after the last video.
  • Bitmap subtitle tracks are not offered.

07Troubleshooting

3D looks split, doubled or distorted

Check the projection (Flat, 180°, Fisheye or 360°), then the stereo layout (mono, SBS or TB), then swap eyes if needed. Software eye alignment does not change the headset's lenses or physical IPD.

Playback stutters

Try a lower-bitrate version of the file and check what your headset's decoder supports. Performance depends on codec, bitrate, resolution and hardware.

Subtitles are missing

Check that a track is selected and the external file is still accessible. Use text subtitles (SRT, ASS, SSA or VTT).

A USB drive doesn't appear

Immivio uses volumes mounted by the system. Check storage permissions and the mount state, then reconnect the drive. Some PICO system paths may remain unavailable.

Reporting a problem

Open an issue in GitHub Issues with your headset, Immivio version, media format and the steps to reproduce it. You can save a local problem log from the app and attach it if you choose. Share a sample only if you are allowed to, and never post passwords or private media.
