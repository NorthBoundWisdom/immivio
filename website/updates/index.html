What’s changing in Immivio.

Read the changes for each release tag. Android APKs are attached after build verification; check the version shown by the download selector and the notes accompanying your package.

v0.9.6 — November 6, 2026

Video-only libraries, one network entry and smoother playback controls. Tagged APKs are attached after both build hosts pass verification.

  • Keep the transport, title and timeline visible when opening subtitles, settings, queues and bookmarks, including during small head-follow movements. Preserve hover feedback while new popup controls wait for their displayed frame.
  • Use one shared inset around file-browser content, centred grids/lists and inset scrollbars. Keep the window visible when switching Settings and Network media.
  • Bring SMB, DLNA, Emby, Jellyfin, Plex, Stash and XBVR into one Network media entry. Add/manage sources directly with complete titles; delayed background listings no longer close source setup.
  • Remove photo playback, galleries, spatial/HEIF decoding and photo gestures. Local libraries show videos and folders; migration retires old photo preferences/history without deleting original media.
  • Lower menus by 12 cm by default. Settings → Display → Window height adjusts the saved offset from −60 to +30 cm.
  • Default builds use the appstore channel without a Check for updates button. GitHub tag packages use web/Release and retain the explicit update check.
  • Add English and Chinese Privacy Policy and Terms of Use pages. The maintainer collects no user data; local storage, optional media services, voluntary feedback and website hosting are explained separately.

Playback changes passed host regressions and moving-viewer GPU pixel checks. The PICO development package was installed for device acceptance; headset comfort and media compatibility remain device-dependent. Bitmap subtitles remain unsupported.

v0.9.5 — November 5, 2026

Dual text captions, selected media-source improvements and a clearer curved interface. Quest, PICO and experimental OpenXR APKs are attached to the tagged release after both build hosts pass verification. Source archives alone are not installable apps.

  • Dual text subtitles, Primary/Secondary track selection, shared delay and per-video memory. Flat captions can sit below rotated or reclined screens.
  • External-subtitle encoding detection, per-track overrides and filename filtering. Failed conversion keeps the original track without rewriting the source.
  • Emby/Jellyfin direct-play version selection, folder compatibility and history-controlled playback reports. Cross-client non-default-version resume remains limited.
  • Eligible Android Open/Share video entry, manual update checks and runtime-advertised refresh rates with a preference for 72 Hz.
  • Clearer CJK text, filled dropdowns and unselected controls, persistent navigation and UI warmup for all six entry types. Playback and photo pages use viewing-distance curvature.
  • Show playback controls once the first frame resolves their layout. File browsing, settings, subtitles, queues and bookmark pages are mutually exclusive. Smooth hover outlines and neutral ray feedback on the title and battery/clock pills; information panels do not trigger actions or dismiss controls.
  • Flat-video placement from 0.1–50 m and 5–3000%, with library/menu distance up to 4 m. Photos retain their separate ranges.
  • Grip-stick immersive placement, per-file preferences, the fixed left palm-menu gesture and a separate pinch-hand setting. Lists and captured controls retain input priority.
  • Bounded, redacted local crash trails with manual export, plus clearer USB permission/fallback feedback. Device comfort and media compatibility still need matching hardware acceptance.

Text captions only: bitmap subtitles remain unsupported. Cross-client resume for non-default server versions remains limited. Latest UI changes passed host, GPU pixel and Android emulator checks; physical headset interaction and comfort still need matching device acceptance.

v0.9.4 — October 24, 2026

  • Play STRM shortcuts from local files, SMB and compatible HTTP sources. Show loading stages, elapsed waiting time, measured video input speed and readable playback errors.
  • Remember folder positions and per-folder sorting, switch between list and icon views, and browse in a compact or full library while playback controls remain available.
  • Lock playback controls in space and adjust their background opacity. Use flat-screen TV/cinema presets, distance, size, curvature, eye height and fixed viewing defaults.
  • Fix native library/toolbar display and ray mapping, cinema preset selection and logarithmic distance adjustment. Hide idle controllers during video viewing.
  • Use the independent Android ID com.northboundwisdom.immivio. It installs separately from the legacy player; data is not migrated automatically. Keep project-local signing independent of company products.
  • Add a PICO launcher that reuses the running VR player on repeated opens. On PICO, the sideloaded VR entry is available under Library → Unknown sources → Immivio.
  • Remove cloud-drive and WebDAV integrations. Local files, SMB, DLNA and supported media servers remain available; dependency preparation is simpler.

Selected changes passed automated checks on a physical PICO 4. Compatibility and interaction still depend on the headset and media source.

v0.9.2 — October 14, 2026

  • Use one compact playback toolbar with individual popups for subtitles, speed, grading, eye alignment, timing, queues and source information.
  • Place the filename beside the battery and clock, shorten long names in the middle, keep Close separate and centre previous/play/next. Controls sit 20% closer with a lower timeline and less empty space.

  • Update the About repository link and remove the contact email.

v0.9.0 — October 13, 2026

  • One media player for existing stereo and spatial content. Live AI depth, person matting and model-based photo conversion have been retired.
  • Remember explicit audio and subtitle choices per video, volume and mute across launches. Double-tap the volume icon to mute or restore sound.
  • Choose from five text-subtitle palettes and adjust audio/subtitle timing independently. Saved queues support repeat, shuffle and automatic advance.
  • Arrange photo walls in 1–3 rows, retain per-video eye alignment and read long library filenames in expanded hover tips.
  • Keep DLNA subtitles when metadata is incomplete, and recover the library position when closing a video.
  • Refactor playback frame validation and resource ownership, remove retired inference buffers, and split application controllers for continued maintenance.
  • Simplify dependency management with preinstalled development tools, a verified OpenXR addon archive and verified Android playback libraries.

This milestone completed the playback refactor and dependency-management simplification, with local regression and Android packaging checks. See v0.9.1 above for the subsequent PICO device fixes.

Choose the package for your headset.

Use the Quest or PICO APK for those devices. Generic OpenXR is experimental and needs a compatible Android runtime. Source ZIP/TAR archives are for developers.

Text subtitles and packed SBS/TB video use the same playback pipeline in all packages. Bitmap subtitle tracks are not offered. MV-HEVC dual-view video and Dolby Vision colour correctness have not been validated; file names alone do not establish support.

Updates need a matching Android application identity and signing key. Packages signed by another distributor or temporary CI keys may require a separate installation.

Immivio has no 2D-to-3D conversion or person-matting edition. Historical releases may describe features that have since been removed.

History and source changes

Immivio continues independently from the original 0.6.0 baseline. Published releases carry their own package notes; the source changelog retains earlier milestones.

Developer setup now uses preinstalled host tools and Android media libraries. Gradle manages application packages, and the OpenXR addon is prepared and verified separately. See building from source.
